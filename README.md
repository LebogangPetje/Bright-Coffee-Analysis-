# Bright-Coffee-Analysis

Overview:
 This project analyses historical sales data from Bright Coffee Shop to uncover business insights for the new CEO. The goal   is to identify which products drive the most revenue, determine peak sales periods, and recommend strategies to improve overall performance.

Objectives:
	Identify high- and low-performing products.
  Analyse sales trends by product and time of day.
  Visualise total revenue, sales quantity, and time-based performance.
  Provide actionable recommendations for growth.
  
Tools Used:
  SQL (Snowflake, MySQL, or BigQuery) for data cleaning and transformation.
  Excel / Power BI / Tableau for data visualisation.
  Miro for planning and architecture design.
  PowerPoint / Canva for the final presentation.
  
Process Summary:
	Data Preparation: Cleaned and formatted raw sales data (converted commas, created time buckets, calculated total revenue).
  Analysis: Grouped transactions by product and time intervals to identify key sales patterns.
  Visualisation: Built dashboards to display insights clearly and effectively.
  Recommendations: Suggested marketing, stock, and automation improvements based on findings.
  
Deliverables:
 Miro Architecture Diagram
 Processed Excel Dataset (with pivot tables and charts)
 SQL Script
 PowerPoint Presentation (insights + recommendations)
